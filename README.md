# 🛡️ SENTINEL-X AI Security Audit (Prank Simulation)

An ultra-realistic, high-fidelity, interactive cybersecurity threat audit & live endpoint telemetry simulation built with HTML5, CSS3, JavaScript, WebGL (Three.js), GSAP, and synthesized Web Audio.

Designed as a **harmless browser prank**, SENTINEL-X mimics a high-tech federal/corporate AI threat detection matrix while ensuring **100% safety, zero data collection, and complete privacy**.

---

## 🌟 Key Features

* **⚡ Real Client Telemetry (Non-Invasive)**:
  * **WebGL GPU Detection**: Identifies the user's actual graphics card model (e.g., *Apple M2*, *NVIDIA RTX 4080*, *Intel Iris Xe*).
  * **Host OS & Version**: Parses browser environment for accurate OS detection (*macOS*, *Windows 11*, *Android*, *iOS*, *Linux*).
  * **CPU & Display Specs**: Reads logical CPU thread counts (`hardwareConcurrency`), screen resolution, pixel density, and local timezone.
* **📂 OS-Tailored FileSystem & Kernel Logs**:
  * Dynamically matches fake vulnerability scan paths and process logs to the target's specific operating system (`/Users/$USER/Library/Keychains/...` on macOS vs `C:\Users\%USERNAME%\AppData\...` on Windows).
* **🎨 3D Holographic Core & Multi-Canvas Visuals**:
  * Interactive 3D wireframe core rendered using **Three.js**.
  * Particle rain, cyber grid floor, global threat relay node map, laser iris & fingerprint biometric scanners.
* **🔊 Synthesized Web Audio Engine**:
  * Real-time procedural sound effects using Web Audio API (low-frequency hums, frequency sweeps, alert alarms, static bursts).
* **📜 Complete Prank Disclaimer & Educational Note**:
  * Concludes with an unmistakable prank reveal overlay, reassuring users that **zero hacking occurred**, **no network requests were made**, and **no personal files were touched**.
  * Includes cybersecurity educational tips and a 1-click share button to prank friends.
